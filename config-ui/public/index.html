小米音箱

用于连接米家账号和指定音箱
必须与米家 App 中显示的名称完全一致。
如果使用 Cookie 授权，在此粘贴；不要发到聊天。
新手：这些信息在哪里获取？
  • 小米 ID：打开 account.xiaomi.com 的个人信息页，复制“小米 ID”，不是手机号。
  • 音箱名称：打开米家 App，进入音箱设备详情，填写页面显示的设备名称，必须完全一致。
  • API Key、Base URL、模型：从你的中转站控制台复制。Base URL 通常以 /v1 结尾，模型填写控制台提供的模型 ID。
  • passToken：仅在验证码授权反复失败时使用。它等同账号凭据，只保存在本机，绝不要发给别人或上传 GitHub。
安全提醒：此页面只监听本机 127.0.0.1。不要把 .env、.migpt.js、.mi.json 或桌面启动脚本上传到公开仓库。
配置文件位置：当前项目目录下的 .env、.migpt.js、.mi.json
