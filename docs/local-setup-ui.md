# 本地配置页面

双击桌面上的 `打开 MiGPT 配置.command`，页面会打开在 `http://127.0.0.1:8765`。

## 第一次使用

1. 在 API 服务商控制台创建或复制 API Key、Base URL 和模型 ID。
2. 在 [小米账号个人信息页](https://account.xiaomi.com/fe/service/account/profile) 复制“小米 ID”，不是手机号。
3. 在米家 App 的音箱设备详情中复制设备名称，名称必须完全一致。
4. 如果普通账号密码登录触发异地验证，可在页面填写从已登录小米账号 Cookie 获取的 `passToken`；它与密码同等敏感，不能发给别人，也不能提交 Git。
5. 点击“保存配置”，再点击右上角“启动AI版小爱同学”。

## 后续使用

已经保存过配置后，打开页面即可直接点击“启动AI版小爱同学”，不必再次填写。点击“检查 AI 是否已连接”会向 Base URL 的 `/models` 接口发起无对话、无生成费用的连接检查。

配置页面只监听本机回环地址，不对局域网或公网开放。真实配置写入 `.env`、`.migpt.js`、`.mi.json`，这三个文件已加入 `.gitignore`，不会随项目上传。
